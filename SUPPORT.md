# Getting help

Start with the [installation guide](docs/installation.md),
[troubleshooting guide](docs/troubleshooting.md) and
[compatibility table](docs/compatibility.md).

- **Questions and setup help:** [GitHub Discussions](https://github.com/eduardobittencourt/tuya-camera-ha/discussions).
- **Reproducible bugs:** [bug report](https://github.com/eduardobittencourt/tuya-camera-ha/issues/new?template=bug_report.yml).
- **Working or incompatible camera models:** [compatibility report](https://github.com/eduardobittencourt/tuya-camera-ha/issues/new?template=compatibility_report.yml).
- **Feature ideas:** [feature request](https://github.com/eduardobittencourt/tuya-camera-ha/issues/new?template=feature_request.yml).
- **Credential exposure or vulnerabilities:** [private security reporting](SECURITY.md).

Include the retail camera model, firmware, Tuya Smart/Smart Life app, HA and
integration versions, installation type and host architecture. Explain whether
discovery, video, audio and snapshots work separately. State the test duration.

Do not post raw logs, API responses, `.storage`, backups, tokens, device IDs,
serial numbers, stream URLs or private images. Review any diagnostics before
attaching them. Nobody needs your password to review a public issue.

This is an independent community beta maintained by volunteers. Responses and
device support are not guaranteed. Help is available in English or Portuguese.
