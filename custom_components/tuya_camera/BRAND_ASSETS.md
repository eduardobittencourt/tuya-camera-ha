# Tuya brand images

These images identify the Tuya platform supported by this integration. They
are the existing Tuya assets from the Home Assistant Brands repository:

- Source: https://github.com/home-assistant/brands/tree/master/core_integrations/tuya
- Retrieved: 2026-10-05
- `icon.png`: 256×256
- `icon@2x.png`: 512×512
- `logo.png`: 512×256
- `logo@2x.png`: 1023×512

Tuya's names and logos are trademarks of their respective owners. The images
are not licensed under this project's MIT software license. Their use is for
identification and does not imply affiliation or endorsement.

Home Assistant 2026.3+ loads these files from the integration's `brand/`
directory. This project requires HA 2026.9+, so a separate submission to the
Home Assistant Brands repository is not required for local icons.
